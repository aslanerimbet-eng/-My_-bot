# CRMP Shop Bot

Telegram-бот для продажи проектов, модов и услуг разработки по CRMP.

## Возможности

- 🔒 Обязательная подписка на канал при старте и при любом действии
- 🎮 **Проекты**, 🛠 **Моды**, ⚙️ **Разработка**: карточки с описанием, ценой и картинкой
- 🛒 Кнопка «Заказать»: заявка приходит админу, клиенту показывается контакт продавца
- 💬 **Отзывы**, 📢 **Канал**: ссылки
- 🆘 **Поддержка**: контакт продавца

## Файлы

| Файл | Назначение |
|------|-----------|
| `bot.py` | код бота (трогать не нужно) |
| `config.py` | **все настройки: названия, цены, описания, ссылки, картинки** |
| `requirements.txt` | зависимости |
| `Procfile` | команда запуска для хостинга |
| `*.jpg` | картинки для карточек (лежат рядом с `bot.py`) |

## Как всё настроить самому

Откройте `config.py` (на GitHub: файл → значок карандаша → править → Commit changes).
Хостинг обновит бота автоматически.

- `CHANNEL_ID`, `CHANNEL_LINK` — канал для обязательной подписки.
  **Бот должен быть администратором этого канала**, иначе проверка подписки не работает.
- `REVIEWS_LINK` — ссылка на отзывы.
- `SUPPORT_USERNAME` — юзернейм продавца без `@`.
- `PROJECTS`, `MODS`, `DEV` — товары. Чтобы добавить новый, скопируйте строку
  `{...}` и поменяйте `id` (уникальный), `name`, `desc`, `price`, `photo`.

### Картинки

Загрузите картинку в репозиторий рядом с `bot.py` и укажите её имя в товаре:
`"photo": "mod_v3.jpg"`.
Для нескольких картинок (альбом до 10 штук) укажите список:
`"photo": ["mod_v3_1.jpg", "mod_v3_2.jpg"]`.

## Переменные окружения (на хостинге)

| Переменная | Что это |
|-----------|---------|
| `BOT_TOKEN` | токен от [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | Telegram ID админа, куда приходят заказы |

Токен нельзя писать в код и загружать в репозиторий.

## Деплой (Railway)

1. Загрузите файлы в репозиторий GitHub.
2. Railway → New Project → Deploy from GitHub repo.
3. Вкладка Variables: добавьте `BOT_TOKEN` и `ADMIN_ID`.
4. Railway сам найдёт `Procfile` и запустит бота. Отправьте боту `/start`.

Запускайте только одну копию бота с одним токеном, иначе будет ошибка `Conflict`.
